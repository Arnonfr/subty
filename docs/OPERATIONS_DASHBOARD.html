Subty Operations Dashboard

Live status: Ready for analytics + remote controls in Firebase.

1) Where Data Is Stored

  • Firebase Analytics (GA4): events + funnels + usage insights.
  • Firebase Remote Config: runtime feature flags and global control.
  • On-device local store: per-device monthly quota display (X/10).

2) Global Controls

  • translate_enabled=false -> blocks Translate for everyone, keeps Download active.
  • app_enabled=false + maintenance_message -> full maintenance mode.
  • search_enabled=false -> disable search globally.
